# SAVORA — Luxury Restaurant Website Concept

A responsive, multi-section restaurant website built with semantic HTML, CSS, and vanilla JavaScript. It is a self-initiated portfolio concept, not a real restaurant or client project.

## Run it

1. Extract the `savora-restaurant.zip` archive.
2. Open `index.html` in a modern browser. No Node.js or npm is required.
3. For a better local development workflow, open the folder in VS Code and use the Live Server extension if you already have it installed.

## Features

- Responsive desktop, tablet, and mobile layouts
- Mobile navigation and active-section navigation state
- Filterable menu categories
- Dish detail dialogs
- Gallery lightbox with previous/next controls and arrow-key navigation
- Reservation demo with client-side validation and printable sample confirmation
- Contact form validation (does not send or store data)
- Reduced-motion support and lazy-loaded images below the fold
- Clear portfolio-concept disclaimer

## Important limitations

- Reservation confirmations are simulated locally. No table is booked and no booking data is transmitted.
- Contact form submissions are not emailed or stored.
- Menu, prices, chef/restaurant concept, and location are illustrative.
- Photos and fonts load from third-party web URLs, so internet access is needed for them to appear.
